# Backend Scripts

## Collection Seeder

Tạo dữ liệu mẫu cho Collections.

### Usage
```bash
cd mer-backend
npm run seed:collections
```

### Data Includes
- Custom Collections (4)
- Seasonal Collections (2)
- Trending Collections (2)
- New Arrival Collections (2)
- Best Seller Collections (2)

See [docs/FEATURES.md](../../docs/FEATURES.md) for complete feature documentation.
